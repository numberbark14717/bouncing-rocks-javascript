# How to install and play the game:

## Installing:
1. To make sure the game works, you need to go to the "releases" section. This way, you’ll find the complete and working versions.
2. Pick the most recent one if you want to be sure it includes the latest patches.
3. Download the version you’re interested in, and when it’s done, go to your PC’s file explorer and open "downloads."
4. There, you’ll find a zip folder named after the game and its version.
5. Extract everything from the folder.
6. At this point, you’ll end up in a folder containing other subfolders and files.
7. The only one that matters is called "start_game.bat."
8. Select the file and run it (double-click on it). A window with some text will open.
9. ***WARNING:*** during gameplay or loading, ***do not*** close this window because it’s the one that allows the game to start and run.
10. The default browser will open with the game running, and you’ll be ready to play.
